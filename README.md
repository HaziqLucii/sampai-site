# sampai-site

The website for **Sampai**, a nag-until-done reminder app for Android: a reminder that rings again every 1, 5, 10, 15, 30 or 60 minutes until you tap Done.

- `/` landing page
- `/privacy/` privacy policy (linked from the Play listing)
- `/terms/` terms of use

Static HTML and CSS, served by GitHub Pages. Scroll animations use GSAP with ScrollTrigger and SplitText, and Lenis for smooth scrolling, vendored under `assets/vendor/`. Everything is static and complete without JavaScript, and motion is off for visitors who ask their system to reduce it.
